# ??? AdGuard Custom Blocklist

Eine hochgradig kuratierte Liste zur Filterung von Werbung, Tracking-Diensten und schädlichen Websites, optimiert für AdGuard Home.

---

## ?? Betriebskosten
Die Bereitstellung der Liste über GitHub ist **kostenlos** (0.00 €). Für den Betrieb von AdGuard Home wird ein Raspberry Pi oder ein kleiner VPS (~3.00 €/Monat) benötigt.

---

## ??? Setup & Einbindung
1. Kopiere die Raw-URL der locklist.txt Datei aus diesem Repository.
2. Öffne das AdGuard Home Webinterface.
3. Navigiere zu **Filter -> DNS-Sperrlisten**.
4. Klicke auf **Sperrliste hinzufügen -> Benutzerdefinierte Liste hinzufügen**.
5. Füge die Raw-URL ein und aktiviere die Liste. Die Updates erfolgen ab dann automatisch.
